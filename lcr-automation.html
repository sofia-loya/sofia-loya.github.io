LCR Meter Data-Collection Automation

A project I owned end to end: a Python tool that talks directly to an LCR meter, captures its impedance measurements, runs the required calculations, and collapses a 99-point manual test into a single automated output file.

// situation

A full day of hand-recording 99 data points

The capacitive coupling test method required an operator to manually read and record 99 impedance data points from an LCR meter for a single catheter. It was slow and error-prone — a single unit could take up to a full day — and it pulled skilled operators into repetitive transcription instead of higher-value work.

// task

Automate the whole collection loop

Own the automation end to end: build a tool that communicates with the LCR meter directly, captures its measurements, performs the required calculations, and produces one clean data file — removing manual transcription from the process entirely.

// action

A direct serial link, built for reliable readings

  • Talked to the instrument directly. Established serial communication with a Hioki IM3536 LCR meter over USB using Python and pySerial, so measurements are read straight off the meter rather than typed in by hand.
  • Structured the workflow. The tool generates a fresh output file seeded with the test's base information, then prompts once for the meter settings and operator details before collection begins.
  • Designed for measurement quality. Implemented a discard-first-reading pattern to drop the meter's unsettled initial sample at each point, improving the reliability of the logged values.
  • Captured and computed automatically. As the operator steps the connection through the electrode set, the tool records each measurement, performs the required impedance calculations, and logs everything to a single CSV.
// result

99 manual steps, reduced to one output file

  • Collapsed 99 manual data-entry steps into a single automated output file, removing hand transcription and the errors that came with it.
  • Cut the data-collection burden of a test that previously took up to a full day per catheter.
  • Built to support the team's ongoing testing on this method after the internship.
  • Scoped the next step — a relay-based switching network (reed relays driven by shift registers) to automate the physical connections as well, moving toward a fully hands-off test.
